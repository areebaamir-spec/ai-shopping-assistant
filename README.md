# AI Shopping Assistant

AI Shopping Assistant is a web-based ecommerce recommendation system developed as a Final Year Project (FYP). The system allows users to browse products, submit natural language product queries, and receive relevant product recommendations using Natural Language Processing (NLP).

## Features

* Product Browsing
* NLP-Based Recommendation Interface
* Product Recommendation Generation
* Product Details Display
* User Authentication (Login & Signup)
* Shopping Cart Management
* Admin Product Management
* Responsive Frontend Interface

## Technologies Used

* **Backend:** Django
* **Database:** MySQL
* **NLP Library:** spaCy
* **Frontend:** HTML, CSS, JavaScript

## System Architecture

The project follows an MVC-based architectural approach consisting of:

* Presentation Layer (Frontend)
* Application Layer (Backend)
* Data Layer (Database)

The system integrates frontend interaction, backend processing, NLP-based query handling, and database communication for recommendation generation and shopping operations.

## NLP Functionality

The recommendation module processes user queries using:

* Text Normalization
* Tokenization
* Stopword Removal
* Lemmatization
* Keyword Extraction

The extracted information is used to retrieve relevant products from the database.
